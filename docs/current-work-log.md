# ASK-18 작업 기록

- ASK-19의 Jira 완료, React PR #33 병합 커밋과 월별 devlog를 확인했다. ASK-26 UI 명세가 합쳐진 원격 Specs main을 대조했다.
- 원격과 같은 React develop에서 작업 브랜치를 만들고 ASK-18을 진행 중으로 전환한 뒤 재조회했다.

- 작성·수정 공통 폼에 첨부 선택, 형식·빈 파일 검사, 개별 제거, 중복 제출 방지를 추가했다. 수정은 새 파일만 보내고, 상세는 백엔드 URL의 이미지와 PDF를 표시한다.
- 독립 리뷰에서 캐시가 있는 재조회 실패 시 첨부 선택이 사라지는 문제와 계정이 교체될 때 이전 작성 폼의 파일이 남을 수 있는 문제를 확인했다. 일시 실패 중 폼을 보존하고, 수정 권한 재확인 중에는 제출을 차단했다. 인증 세대별로 폼을 분리하고 두 변경 요청 직전에 세대를 확인한다. Architect 재리뷰에서 추가 필수 지적은 없었다.
- `npm run lint`, `npm run build`, `node --test tests/*.test.mjs`(26개 통과, ASK-14 옵트인 1개 미실행), `git diff --check`를 확인했다.
- 실제 Chrome 157, Vite preview, 테스트 프로필의 Spring H2·전용 Redis·임시 업로드 저장소에서 작성·수정 각 3회와 본문·첨부 상세를 검증했다. 첨부 없음, 형식과 빈 파일 검사, 선택 제거, 이미지와 PDF 혼합 전송, 연속 제출, 실제 서버 용량 초과 400 및 폼 보존, 기존 파일 보존, 공개 조회와 비작성자 수정 접근 제한, 이미지 로딩 실패 시 본문 표시를 확인했다. JavaScript 예외 및 `console.error` 호출은 없었다.
